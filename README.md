Описание краткое плана проекта:

Цели проекта

Выявить закономерности, определяющие успешность компьютерных игр — чтобы делать ставку на потенциально популярные продукты и эффективно планировать рекламные кампании для интернет-магазина «Стримчик».

Отработать принцип работы с данными на примере исторических продаж — чтобы в будущем можно было прогнозировать продажи и принимать обоснованные решения на основе анализа данных.

Задачи проекта

Изучить исходные данные
Открыть и получить общую информацию о предоставленном датасете игр.
Подготовить данные для анализа
Привести названия столбцов к единому стилю (нижний регистр).
Преобразовать данные в нужные типы (описать, где и почему).
Обработать пропуски (аргументировать выбор метода и причины появления пропусков).
Особо обработать значение 'tbd' в пользовательских оценках.
Посчитать и добавить столбец с суммарными продажами по всем регионам.
Провести исследовательский анализ данных (EDA)
Оценить количество выпускаемых игр по годам и выбрать актуальный период для анализа.
Проанализировать динамику продаж по платформам, выявить лидеров и перспективные платформы.
Построить и проанализировать распределение глобальных продаж по платформам («ящик с усами»).
Исследовать влияние отзывов пользователей и критиков на продажи для популярных платформ (корреляция, диаграмма рассеяния).
Проанализировать распределение игр по жанрам и прибыльность жанров.
Составить портрет пользователя для каждого региона (NA, EU, JP)
Определить топ-5 популярных платформ в каждом регионе и сравнить их.
Определить топ-5 жанров в каждом регионе и сравнить их.
Проанализировать влияние рейтинга ESRB на продажи в каждом регионе.
Проверить статистические гипотезы
Проверить, равны ли средние пользовательские рейтинги платформ Xbox One и PC.
Проверить, различаются ли средние пользовательские рейтинги жанров Action и Sports.
Самостоятельно выбрать пороговое значение alpha, сформулировать нулевую и альтернативную гипотезы, обосновать выбор критерия проверки.
Сформулировать общий вывод по результатам анализа
Суммировать ключевые инсайты и рекомендации по ассортименту и рекламным стратегиям на следующий год.
